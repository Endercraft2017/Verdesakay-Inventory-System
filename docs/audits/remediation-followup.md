## Evidence and unresolved gates

See `validation-results.md` and `evidence/` for final command results. New regressions cover browser/console CSRF, no browser token body/storage, cookie isolation between path tenants, WebSocket origin/revocation, stale access revocation, queue actor binding, CSP nonces and public policy allowlisting. Playwright also checks that the PWA IndexedDB credential is null and cookie WebSockets work under CSP.

Missing-CSP is resolved. This is not an authenticated independent penetration test or verification of a real reverse proxy. The scanner also recorded 3 errors/19 warnings and warned about add-on freshness; its coverage is limited. Original and repeat reports are preserved separately.
