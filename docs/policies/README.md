# Product policies — approval required

These documents describe the application inspected on this branch. They are working drafts, not executed contracts or a compliance certification. An owner must fill every `[OWNER: ...]`, approve the actual practices, obtain appropriate legal review, and set an effective date before accepting paying customers. The product links expose this draft status prominently.

Public pages: `/policies`, `/policies/privacy`, `/policies/terms`, `/policies/refunds`, `/policies/security`, `/policies/data-rights`, `/policies/ai`.

Approval record: legal entity [OWNER]; policy owner [OWNER]; reviewer [OWNER]; jurisdiction [OWNER]; version/effective date [OWNER]; approved commit [OWNER]. Keep previous approved versions and notify customers of material changes. The request process below is manual; the application does not implement universal deletion or statutory deadline automation.

Internal templates and operating procedures: `docs/governance/` and `docs/operations/`. Release decisions and missing owner inputs: `docs/OWNER-ACTIONS.md`.
