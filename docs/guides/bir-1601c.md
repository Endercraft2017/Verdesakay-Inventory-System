# BIR Form 1601-C (monthly withholding)

The **Monthly Remittance Return of Income Taxes Withheld on Compensation** — the return
you file and the tax you remit every month.

## What it's for

- File and pay by the **10th of the following month** (15th if you're on eFPS).
- The 12 monthly returns for a year should **reconcile to the annual 1604-C**.

## Steps

1. **Time Keeping → 1601-C** (needs HR view).
2. Pick the **year**. The table shows every month:
   - **Employees** paid that month
   - **Gross compensation** (from the payslips)
   - **Non-taxable** — the SSS / PhilHealth / Pag-IBIG employee shares
   - **Taxable compensation**
   - **Tax withheld** — the amount to remit on that month's return
3. Use each month's **Tax withheld** as the figure for that month's 1601-C.
4. **Export CSV** for your records or your accountant.

## Watch out

- The figures come from the **payslips generated** for the year — run all your cutoffs
  and Generate Payslips first, and set the correct **pay date** on each run (that's how
  a payslip lands in a month).
- **13th-month pay is not a payslip line.** If you release it in December, add it to
  December's 1601-C manually (the non-taxable portion up to ₱90,000, the excess as
  taxable).
- De-minimis benefits and allowances aren't tracked either — adjust the month's figures
  if they apply.
